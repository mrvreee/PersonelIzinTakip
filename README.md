--- Personel İzin Takip Sistemi ---

 📌 Proje Hakkında

Personel İzin Takip Sistemi, kurumlarda çalışan personellerin izin süreçlerini dijital ortamda takip etmek ve yönetmek amacıyla geliştirilmiş bir Java masaüstü uygulamasıdır.
Uygulama sayesinde personel bilgileri görüntülenebilir, personellerin izin kayıtları takip edilebilir, geçmiş izin bilgileri incelenebilir ve izin durumları raporlanabilir.
Proje, Java programlama dili kullanılarak geliştirilmiş ve SQL Server veritabanı ile entegre edilmiştir.

 🚀 Projenin Amacı
Bu projenin temel amacı, personel izin süreçlerinin daha düzenli, hızlı ve güvenilir bir şekilde yönetilmesini sağlamaktır.
Sistem ile:
- Personel kayıtlarının yönetilmesi
- Personellerin izin bilgilerinin takip edilmesi
- Geçmiş izin kayıtlarının görüntülenmesi
- İzin bilgilerinin raporlanması
- Verilerin SQL Server üzerinde güvenli şekilde saklanması
amaçlanmaktadır.

Personel ve izin bilgilerinin kullanıcıya tablo şeklinde sunulması ve raporlanması.

🗄️ Veritabanı
Projenin veritabanı Microsoft SQL Server kullanılarak oluşturulmuştur.
Java uygulaması ile SQL Server arasındaki bağlantı JDBC üzerinden gerçekleştirilmektedir.
Veritabanı işlemlerinde PreparedStatement kullanılarak SQL sorgularının daha güvenli ve düzenli şekilde çalıştırılması hedeflenmiştir.
